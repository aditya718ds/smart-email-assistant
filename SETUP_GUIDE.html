What you received: a new implementation of the Smart Email Assistant shown in the EmbarkX tutorial, with full source, a compiled runnable JAR, an offline template demo and a Gmail extension. It recreates the workflow with a redesigned interface; it is not a byte-for-byte copy of the tutorial repository.

1. Run the working demo

Java 17 through 27 is required. Java 27 was found on the system used for this delivery. The launcher detects Java automatically, even if it is missing from PATH. For another computer, install Eclipse Temurin Java 21 LTS first.

01Extract the ZIP

Right-click SmartEmailAssistant.zip → Extract All. Open the extracted SmartEmailAssistant folder.

02Double-click START.bat

A terminal starts the backend and opens your default browser. Keep the terminal open.

03Generate a demo reply

Click Meeting, choose a tone and click Generate demo reply. Edit, copy or download your draft.

The app is available at http://127.0.0.1:8080. If the browser does not open, enter this address manually. Press Ctrl+C in the terminal to stop the app.

No database, IDE, Maven or Node.js installation is required for this normal run. The JAR contains the backend, dependencies and built React interface.

Demo mode is not AI. It chooses from a few offline templates for meetings, interviews, support and general replies. Optional instructions appear as reminders in brackets. Replace all placeholders yourself. Follow the next section for real contextual AI generation.

2. Enable genuine AI replies

  1. Open Google AI Studio → API keys, sign in to your Google account, and create your own Gemini API key.
  2. Open config.properties in Notepad. Replace the settings with the following, using your key:
assistant.mode=gemini
assistant.gemini.api-key=PASTE_YOUR_KEY_HERE
assistant.gemini.model=gemini-3.5-flash-lite
  1. Save the file without changing its name or adding a .txt extension. Enter values without quotes.
  2. Stop the running app with Ctrl+C, then double-click START.bat again.
  3. The badge should say Gemini configured. Paste a sample email and click Generate AI reply. This first generation checks whether the key and model actually work.

The configured badge means a key is present; it does not verify credentials, quota or access. If Gemini reports the model is unavailable, replace the model ID with one available in your AI Studio account that supports generateContent, then restart. API quotas, billing and model availability are controlled by Google.

Where the key goes

The key stays in your local backend configuration and is sent to Google in the x-goog-api-key request header. It is never included in the React page or extension. Do not share your configured file or commit it to Git. In Gemini mode, clicking Generate sends the submitted email, instructions and sign-off name to Google. The app itself does not store email history.

Switch back to offline mode

Set assistant.mode=demo and restart. Offline mode sends no AI requests.

3. Add the optional Gmail extension

  1. Start the local app and keep it running on port 8080.
  2. In Chrome, open chrome://extensions. In Edge, open edge://extensions.
  3. Enable Developer mode and choose Load unpacked.
  4. Select the extracted SmartEmailAssistant\extension folder containing manifest.json.
  5. Open or reload Gmail. Open a received message and click Reply.
  6. Click the purple AI Reply button near the reply editor. A preview panel opens. Review or replace the original email context; the selected text or latest visible message may have been picked automatically.
  7. Choose a tone, add your instructions and click Generate. Edit the resulting draft.
  8. Click Insert into empty draft, or copy the reply into an existing draft. Insertion preserves existing text and signatures by asking you to copy instead of overwriting them.

You send the email yourself. The extension never clicks Send. It only requests a reply when you click Generate. Gmail account access and the unpacked extension were not enabled during testing.

If the Gmail button does not appear

Use the extension's toolbar popup to paste an email and copy a reply, or use the web app. Gmail changes its page structure, which can affect automatic context selection and button placement. Always review the original-email field. To remove the extension, open the Extensions page and click Remove.

5. Troubleshooting

SymptomWhat to do
Java was not foundInstall Java 21 LTS from Adoptium. Alternatively set JAVA_HOME to the JDK folder. The launcher checks common installation folders.
Port 8080 is in useStop a previous app instance with Ctrl+C, or close the app that uses port 8080. The launcher never terminates other programs.
Blank browser page / cannot connectKeep the terminal open, check it for Java startup errors, and reload http://127.0.0.1:8080. Extract the whole ZIP first.
Still says Offline demoSave assistant.mode=gemini in config.properties, then stop and restart the backend. A browser refresh alone does not reload configuration.
API key needed / missing keyFill assistant.gemini.api-key without quotes, save and restart.
Gemini rejected requestCheck the API key, project permissions, supported region and model access in AI Studio.
Model was not foundChoose a model available to your key that supports generateContent; update the model setting and restart.
Quota or rate limitCheck AI Studio quota and billing. Wait for quota availability; repeated clicking does not fix a quota limit.
Timeout / cannot connect to GeminiCheck internet access, proxy or firewall restrictions, and retry. AI requests time out after 45 seconds.
Blocked / output limit responseTry shorter input or rephrase. The app does not present a truncated reply as complete.
Extension cannot connectStart the app on port 8080. Reload the extension, then reload Gmail. Confirm http://127.0.0.1:8080/api/status opens locally.
Insert refuses to replace a signatureThis preserves your existing draft. Copy the generated text and paste it where you want.
Windows blocks a script by organization policyUse a terminal in the project folder and run Java directly as below. If organizational controls prohibit it, follow your administrator's policy.

Manual run with the Java installation found here

In PowerShell, open the extracted project directory, then run:

& 'C:\Program Files\Java\jdk-27.0.1.0.3\bin\java.exe' -jar app\smart-email-assistant.jar

On another computer where Java is on PATH, use java -jar app\smart-email-assistant.jar. Then open the local app.

6. Rebuild and run tests

Only developers changing source need this step. Install a full JDK and Node.js LTS with npm. Internet is needed to fetch build dependencies. Double-click BUILD.bat.

The script installs dependencies using the npm lockfile, runs extension tests, builds React into Spring Boot's static resources, downloads Apache Maven with SHA-512 verification, runs Java tests and replaces the compiled JAR. Tools stay under the project in .tools/. Stop the app before replacing its JAR.

# Manual build, with npm and Maven on PATH
cd frontend
npm ci
npm test
npm run build
cd ../backend
mvn clean verify

Copy backend/target/smart-email-assistant.jar into app/ after a manual build. The app binds to the local machine only; this package is intended for local use.
